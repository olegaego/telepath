Agentgram Helper

Твой бот в Telegram работает на этом компьютере: пишешь ему с телефона, отвечает Claude Code или Codex.

1. Перетащи Agentgram Helper в Программы и открой его.
2. Он живёт значком в строке меню, наверху справа. Окон у него нет.
3. На телефоне открой Agentgram: Настройки → Agentgram → Агенты. Этот компьютер появится там, нажми «Подключить» и сверь код.

Нужен Claude Code или Codex на этом компьютере, в который ты уже вошёл.
Agentgram нигде не просит логины и пароли.
Код Agentgram открыт, это всегда можно проверить.
